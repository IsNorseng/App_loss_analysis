# Анализ окупаемости рекламы приложения

Учебный кейс по маркетинговой аналитике приложения Procrastinate Pro+: исследование привлечения пользователей, удержания и окупаемости рекламных каналов на горизонте 14 дней.

В ноутбуке рассмотрены подготовка таблиц, когортный анализ, CAC, LTV, ROI, конверсия и сравнение сегментов. [Открыть ноутбук «Анализ убытков приложения»](Анализ%20убытков%20приложения.ipynb).

## Запуск и ограничения

Для повторного расчёта нужны Python 3, Jupyter, pandas, NumPy, Matplotlib и seaborn, а также исходные учебные файлы `visits_info_short.csv`, `orders_info_short.csv` и `costs_info_short.csv`. Файлы данных не приложены; пути и структуру столбцов нужно сверить с ноутбуком.

В сохранённом ноутбуке есть незавершённые ячейки и ошибки `NameError`. Расчёты нужно выполнить заново и проверить перед использованием. Это учебный кейс: он не подтверждает эффект от внедрения рекомендаций или финансовый результат реального приложения.
